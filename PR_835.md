## Summary

Closes #835 — PREWAVE-BE-132: retire legacy claim/evidence writes that bypass canonical contract events.

The API no longer exposes or performs authoritative claim/evidence writes. `POST /claims`, `POST /claims/:claimId/evidence` and `PUT /claims/evidence/:evidenceId` now return a stable `410 Gone` (`LEGACY_PROTOCOL_WRITE_RETIRED`) before any side effect. The underlying internal methods (`ClaimsService.createClaim`, `EvidenceService.createEvidence`, `EvidenceService.addEvidenceVersion`) are fail-closed seams that call the same guard, so an internal caller cannot synthesize protocol state either.

### Changes

- Added `src/claims/legacy-protocol-write-retirement.ts`: machine-readable 410 envelope, operation-specific migration guidance, chain-first lifecycle and V2 successor links.
- `claims.controller.ts`: retired write routes, OpenAPI `deprecated: true` + 410 responses, `Deprecation`/`Link` headers on legacy read routes pointing to V2 projections.
- `claims.service.ts` / `evidence.service.ts`: removed the direct `Claim`, `Evidence` and `EvidenceVersion` insert/update code from the retired write methods; no repository, cache or audit call happens on that path.
- Added a non-authoritative IPFS preparation surface (`src/claims/evidence-upload/`): validates a canonical claim identity via the V2 read model, scans content for secrets, pins via `IpfsService`, and returns `IPFS_CONTENT_PREPARED` with `onChainRegistered: false`, `evidenceRegistered: false`, `canonical: false`. Repeated uploads are deterministic (`preparationId` from claim id + CID) and no protocol row is written.
- Registered `EvidenceUploadModule` in `app.module.ts`. No TypeORM entity, repository or migration was added (Prisma/PostgreSQL single-authority decision preserved).
- Updated `API_REFERENCE.md`, `API_AUTHORIZATION_MATRIX.md`, `WORKFLOW_DIAGRAMS.md`, idempotency docs and added `docs/LEGACY_CLAIM_EVIDENCE_RETIREMENT.md` with the chain-first lifecycle, frontend contract, authorization matrix, OpenAPI behavior and the reviewed legacy table/cache/audit retirement plan (no destructive migration).

### Behavior

```json
{
  "statusCode": 410,
  "error": "Gone",
  "code": "LEGACY_PROTOCOL_WRITE_RETIRED",
  "operation": "claim.create",
  "canonical": false,
  "replacement": "Submit a user-signed ClaimCreated transaction ..."
}
```

Claims/evidence become canonical only after the matching finalized event is ingested and projected (`/api/v2/claims`, `/api/v2/claim-read-models/:claimId`, `/v2/claims/:claimId/evidence`). Unknown, delayed, quarantined and reorged states are not synthesized locally.
