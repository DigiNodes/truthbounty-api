## Summary

Fixes the cursor-pagination contract of `GET /v2/governance/role-changes`.

The endpoint sorted by `(blockNumber DESC, logIndex DESC)` but its cursor carried only `blockNumber`, so a page ending inside a block skipped all remaining role-change events in that block. The cursor now carries the full ordering key and is authenticated with the approved signed cursor service (`CursorService`, PREWAVE-BE-040).

- Added a versioned composite cursor helper (`src/v2/governance/role-change.cursor.ts`) with `[blockNumber, logIndex, txHash]` as the position. Block numbers stay decimal strings and are compared as SQL `NUMERIC`, so no JS `Number` precision loss occurs. `txHash` gives a deterministic final tie-break for rows sharing block and log index.
- `listRoleChanges()` now verifies the signed cursor and applies a lexicographic keyset predicate: `block < :block OR (block = :block AND (log < :log OR (log = :log AND tx < :tx)))`.
- The cursor is bound to chain ID, normalized `account`/`role` filters, route, schema version, sort descriptor, release context and expiry. Tampered, expired, wrong-chain, wrong-route and legacy (bare block number) cursors are rejected with `INVALID_CURSOR`. Old block-only cursors are intentionally not migrated because they cannot express the full position; clients restart from the first page (documented in `docs/FINALIZED_CURSOR.md`).
- Fixed latent defects in the approved `CursorService` that prevented it from issuing usable cursors at all: uninitialized `ttlSeconds`, ignored `expiresAtMs`, missing HMAC key for the binding fingerprint, and the test clock being passed under the wrong option name.
- Fixed the invalid `"@anthropic-ai/sdk:` key in `package.json` that made the manifest unparsable and blocked `npm ci`.

## Tests

Added `src/v2/governance/__tests__/governance-read.service.spec.ts` covering all acceptance criteria:

- multiple pages inside one block enumerate every row exactly once;
- cross-block ordering with block numbers above `Number.MAX_SAFE_INTEGER`;
- deterministic tie-break for equal block/log index;
- account/role filters bound into the cursor and rejected when changed;
- tampered, wrong-route, wrong-chain, legacy and expired cursors rejected;
- no gaps or duplicates over an unchanged dataset at several page sizes.
